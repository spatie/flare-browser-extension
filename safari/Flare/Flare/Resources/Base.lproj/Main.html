The extension is on. Allow access to Laravel Cloud in Safari, then connect your Flare account from the extension settings.

Why Safari asks for access

Flare needs access to cloud.laravel.com to read the project name and add links beside Deploy. Safari's permission covers the whole site. The extension only uses the project name to look for a match in Flare.
