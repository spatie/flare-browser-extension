The extension is on. Allow access to Laravel Cloud in Safari, then open Flare's extension settings to connect your account.

Why Safari asks for access

cloud.laravel.com lets Flare read the project name and add a button beside Deploy. flareapp.io lets it connect your account and find the matching project. The extension does not read your application code or Cloud credentials. You approve each website in Safari.
